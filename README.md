# Drxwnify для ПК (beta)

Версия Drxwnify для Windows — закрытое бета-тестирование.

Скачать: [Releases](https://github.com/slvx666/drxwnify_pc/releases/latest)

- `Drxwnify-<версия>.msi` — установщик
- `Drxwnify-<версия>-portable.zip` — без установки: распакуй и запусти `Drxwnify.exe`

Windows 10/11, x64. Это бета: возможны ошибки — пиши в предложку в приложении.

Android-версия: [slvx666/DRXWNIFY](https://github.com/slvx666/DRXWNIFY) · сайт: https://drxwnify.pages.dev
